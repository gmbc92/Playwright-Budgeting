# Playwright Budgeting Automation

Automated end-to-end tests for the **Budgeting** section under **Admin Settings** in the Temelio platform.

This project was developed as part of a QA Engineer take-home assessment.

## Scope

The automated tests focus on the Budgeting functionality and cover:

- Navigation to the Budgeting section
- Positive scenarios
- Negative scenarios
- Budget creation and management flows
- Validation of expected system behavior

## Tech Stack

- Playwright
- TypeScript
